About reconFTW

Professional Bug Bounty & Recon Framework

reconFTW

A powerful automated bug bounty reconnaissance framework that orchestrates dozens of specialized tools for comprehensive subdomain enumeration, OSINT, web analysis, and vulnerability detection.

GitHub

Modules

O
OSINT Google Dorks, GitHub leaks, emails, metadata, cloud enum
S
Subdomains Passive+active enumeration, brute-force, permutations, takeovers
W
Web Analysis Screenshots, crawling, fuzzing, WAF detection, JS analysis
V
Vulnerability Scan Nuclei, XSS, SQLi, SSRF, LFI, SSTI, port scanning
H
Host Port scanning, geo info, CDN detection, service fingerprint
A
Axiom VPS Distributed scanning across cloud fleet
